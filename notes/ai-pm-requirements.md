## 一、核心主题一句话

> **不是"我的业务能不能用 AI"，而是"我的业务哪个环节该用 AI、用什么 AI、怎么算账"。**

## 二、AI 信源推荐

分享者推荐了日常关注的几类信息源：

| 类型 | 代表 | 特点 |
|------|------|------|
| 行业媒体/公众号 | 量子位、新智元 | 有 PR 属性，需自行甄别 |
| 个人 AI 博主 | 数字生命卡兹克、赛博谈谈心 | 搬运外网信息快，关注工程师动态 |
| 项目推荐 | FOUNDRY PARK、AI 工具箱 | 实用，有 prompt 合集和工具测评 |
| 年轻团队 | 特工宇宙、橘子汽水 | 内容有趣，吸引年轻 AI 爱好者 |
| 播客 | 晚点、暗涌、张小军商业访谈录 | 深度访谈 AI 产品（minimax、love art 等） |

> 💡 **小建议**：不管是不是做 AI 产品，关注互联网趋势都需要持续的信息输入。

## 三、AI 产品经理的能力框架

做一个"AI 对话助手"看似简单，背后需要四种能力：

```
                    AI 产品经理能力框架
┌─────────────┬─────────────┬─────────────┬─────────────┐
│  产品原型    │  数据产品    │  AI 技术    │  推荐产品    │
│  （基本功）  │  （采集/埋点）│  （能力边界）│  （标签/策略）│
├─────────────┼─────────────┼─────────────┼─────────────┤
│ 对话界面设计 │ 数据口径对齐 │ 模型选型    │ 用户标签     │
│ 交互细节     │ 埋点方案     │ 多模态能力  │ 召回/排序    │
│ 点赞/点踩    │ 指标定义     │ 能力框架    │ 千人千面     │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

### 具体说明

| 能力 | 为什么需要 |
|------|-----------|
| **产品原型** | 对话框要不要语音输入？要不要快捷入口？历史对话？重复回答按钮？ |
| **数据产品** | 哪些需求被满足了？哪些没有？点赞/点踩的数据从哪来？ |
| **AI 技术认知** | 知道模型能做什么（文本/图像/视频），才不会设计出"不可能"的功能 |
| **推荐产品** | 推荐航班时不仅告诉用户有哪些，还要告诉用户哪天最便宜 |

> 🤔 **一句话总结**：AI 对话助手看起来就是一个对话框，但背后是产品 + 数据 + AI + 推荐的综合体。

## 四、AI 对话助手的深层设计

以"AI 机票助手"为例，一个对话框背后有这些设计细节：

```
用户问："北京飞曼谷的航班推荐"
        │
        ▼
┌─ 回答 Agent ──────→ 直接回答航班信息
│
├─ 推荐 Agent ──────→ 推荐航班 + 哪天最便宜
│
├─ 联想问题 Agent ──→ "你还想知道：曼谷酒店？签证？"
│
├─ 转化引导 Agent ──→ 引导付费/选套餐（商业化）
│
└─ 质检 Agent ──────→ 评估 AI 回答的准确性
```

### 容易忽略的设计点

| 设计点 | 说明 |
|--------|------|
| 相关问题推荐 | 回答完航班后，自动推荐"最便宜的日期"等联想问题 |
| 动态数据接入 | 航班是否晚点/取消，需要调用业务接口，不能只靠知识库 |
| 商业化转化 | 在适当环节引导付费（广告位设计） |
| 答案回溯 | 排查 AI 回答错误的路径，很多快速增长期产品会忽略 |

### 内部推广的血泪教训

> 曾经推 AI 产品给业务部门，上线后准确率不高，业务人员用了几次就**失去信心**，觉得"这个部门做的产品是垃圾"。
>
> **教训**：一旦失去信任，两个月后你说"升级了"，他们也不会再用了。
>
> **改进**：先让一小部分人测试，每个 query 人工检查，确认部门能跑通后再推广。

## 五、子 Agent 的设计哲学

### 核心原则：小步快跑

```
❌ 旧思路：一个子 Agent 从"回答用户"直接绑定到"提升付款转化"
          （跨度太大，目标太远）

✅ 新思路：每个子 Agent 只负责"让用户快速进入下一步"
          （每步提升 10%-20% 就很可观）
```

### 像乐高一样组合

| 子 Agent | 功能 | 可复用场景 |
|----------|------|-----------|
| 产品推荐 Agent | 推荐商品/航班 | 机票、酒店、度假 |
| 联想问题 Agent | 生成相关问题 | 任何对话场景 |
| 质检 Agent | 评估回答准确性 | 客服、问答 |
| 转化引导 Agent | 引导付费 | 电商、旅游 |

> 💡 **关键转变**：不追求"中台化"（太重），追求"模块灵活"——每个子模块可以随时替换，应用到不同业务场景。

## 六、AI 数据分析三阶段

```
        1.0              2.0              3.0
     ┌────────┐     ┌────────────┐    ┌──────────────┐
     │ 查表取数 │ ──→ │ 图表可视化  │ ──→│ 理解业务归因  │
     │Text2SQL│     │ 自动生成报表│    │ 自动分析原因  │
     └────────┘     └────────────┘    └──────────────┘
      较易实现         中等难度          目前很难实现
```

### 各阶段详解

| 阶段 | 做什么 | 难度 | 现状 |
|------|--------|------|------|
| **1.0** | 用自然语言查数据（"昨天 DAU 多少"→ 生成 SQL） | ⭐ | 大部分企业能做到 |
| **2.0** | 自动生成图表，支持权限控制、分析下载 | ⭐⭐ | 部分企业在用 |
| **3.0** | AI 理解业务，自动归因（"奶茶销量为什么降了"→ 拆解维度 → 分析原因） | ⭐⭐⭐ | 目前很少有人做好 |

### 3.0 为什么难？

1. **需要专家经验**：运营专家的分析思路很难系统化教给 AI
2. **维度关系复杂**：一个维度涨了，可能还要额外看其他表，呈散状关系
3. **配合意愿低**：专家觉得"没 AI 我也能做，有了 AI 不一定准"，不愿意配合
4. **只能自上而下推**：除非高层拍板，否则很难推动

> 🤔 **现实**：即使到明年，很多公司仍然在为"智能文书的准确率"而努力。

## 七、AI + 广告：AIGC 素材优化

### 腾讯财报中的 AI 广告增长

腾讯广告增长约 **20%**，特别提到了 AI 能力带来的效果提升。

### AIGC 素材优化做了什么

```
传统流程（高人力）：
  一个产品 → 多个广告位（朋友圈/信息流/公众号）
           → 每个位置不同尺寸
           → 手动制作大量素材

AI 优化流程：
  一张大图 → AI 自动裁切适配不同广告位
           → AI 换背景、优化色彩、润色
           → 结合用户群体千人千面
```

### 效果数据

| 场景 | AI 做了什么 | 效果 |
|------|------------|------|
| 游戏美女图 | AI 风格优化 + 千人千面 | 点击率提升 30%-50% |
| 广告素材制作 | AI 生成 + 自动裁切 | 大幅降低人力成本 |
| 小游戏推广 | 精准用户分析 + 定向推送 | 增长显著（财报提及） |

### 个性化推荐已经到了"产品子集"级别

> 只是口头聊了"翠湖天地"，没搜索过任何东西，小红书就开始推荐翠湖相关帖子，微信公众号也推送汤臣一品、中粮一号。
>
> **现在的推送已经不是"大类目"，而是细到某个产品的子集。**

## 八、需求挖掘方法论：用户旅程地图

### 核心方法：按角色 × 阶段拆解

```
步骤 1：识别业务中的所有角色
         ↓
步骤 2：画出每个角色的阶段（发现→咨询→下单→仓储→收货）
         ↓
步骤 3：在每个阶段列出触点和转化手段
         ↓
步骤 4：标注哪些环节可以结合 AI
         ↓
步骤 5：让 AI 帮你扩展思路（把你的拆解喂给 AI，让它补充）
```

### 实战案例：冻品冷链企业

| 角色 | 阶段举例 | AI 结合点 |
|------|---------|----------|
| 冻品生产商 | 生产管理 | AI 质检 |
| 批发商 | 价格咨询 | AI 对话助手 |
| 零售商 | 商品发现 | 智能推荐 + 库存实时查询 |
| 物流仓储 | 仓储管理 | AI 监测（摄像头 + 识别） |
| 终端采购 | 下单支付 | 智能客服 + 转化引导 |

### 让 AI 帮你拓宽思路

> 把自己的拆解结果喂给 AI，让它补充更多维度。
>
> 比如你列了"下单、支付、仓储、物流"，AI 可能帮你补充"电子合同系统""多渠道支付"等你没想到的点。
>
> **关键心态**：AI 是辅助参考，不是直接做决策。有价值的记录，太激进的就当参考。

## 九、AI + 电商个性化

### 亚马逊 Alexa 的个性化能力

不只是"对话推荐商品"，更厉害的是：

| 能力 | 说明 |
|------|------|
| 标题个性化 | 同一个商品，不同用户看到的标题不同 |
| 图片个性化 | 商品图片根据用户偏好调整 |
| 详情页个性化 | 商品介绍内容针对用户定制 |
| 排序个性化 | 搜索结果排序因人而异 |

### 这种能力的利与弊

```
✅ 好处                        ❌ 风险
├─ 转化率可能提高               ├─ 舆情风险（用户发现"被区别对待"）
├─ 老年友好（用大白话解释参数）  ├─ 影响搜索词商业化收入
├─ 无障碍适配                   ├─ 用户体验不一致
└─ 情感化/年龄分层描述          └─ 实时生成的延迟问题（300ms 定律）
```

### 300ms 定律

> 2017 年的实测结论：**如果系统返回第一个字的响应超过 300ms，用户流失率会下降一半以上。**
>
> 策略：不管回答内容是什么，**确保 300ms 内给用户反馈**。

## 十、AI + 线下门店

### 波司登的电子价签系统

**痛点**：线上知道用户是谁、买过什么，但线下门店不能采集人脸，无法识别顾客。

**解决方案**：

```
电子价签（内置重力/位移传感器）
    │
    ├─ 衣服被拿起 → 记录"被关注"
    ├─ 衣服被试穿 → 记录"被试穿"
    ├─ 试穿后购买 → 记录"转化"
    └─ 试穿后放回 → 记录"未转化"
```

### 数据价值

| 数据 | 用途 |
|------|------|
| 试穿 800 次，只成交 2 笔 | 说明产品本身有问题 |
| 拿了 5 件试，只买 1 件 | 分析另外 4 件为什么不满意 |
| 不同时段的热度分布 | 库存预测、产品改进 |

> 💡 **启发**：线下数据的价值不亚于线上，关键是如何低成本地采集。

## 十一、AI Coach：员工培训

### 培训系统的进化路径

```
1.0  对话式学习        → 新员工和 AI 对话，学习业务知识
     ↓
2.0  语音陪练          → 智能体扮演"难搞客户"，模拟实战
     ↓
3.0  全链路学习管理    → AI 了解你的学习进度，识别知识短板
     ↓
     文档/PPT/音频/视频 → 多形式知识输入
     模拟面试/模拟客户  → 场景化训练
     成长路径追踪       → 后台可视化
```

### 最适合的场景

- 客服新人培训（高频）
- 销售话术训练
- 安全团队知识培训
- 任何"老带新"成本高的岗位

> 💡 **复用性强**：换个行业换个场景，底层逻辑完全一样。

## 十三、关键术语表

|------|------|

## 十四、金句摘录

> 1. **"一旦用户失去信心，他们就觉得你做的产品是垃圾，不会再用了。"** —— 内部 AI 产品推广的血泪教训
>
> 2. **"以前中台化太重，现在 Agent 时代追求的是模块灵活，像乐高一样随时替换。"** —— 架构思维转变
>
> 3. **"不需要让子 Agent 跨那么大步，每个子进程的目标就是让用户快速进入下一步。"** —— Agent 设计原则
>
> 4. **"一个人能做好这件事，不代表他能开发出方法论让机器也做到。"** —— AI 数据分析 3.0 的困境
>
> 5. **"系统返回第一个字超过 300ms，用户流失率下降一半以上。"** —— 2017 年的实测结论
>
> 6. **"现在的推送已经不是大类目了，而是细到某个产品的子集。"** —— 个性化推荐的新趋势
>
> 7. **"AI 是辅助参考，不是直接做决策。有价值的记录，太激进的就当参考。"** —— 使用 AI 的正确心态
>
> 8. **"试穿了 800 次只买了 2 笔，这说明产品本身有问题。"** —— 线下数据采集的价值
>
> 9. **"读者对漫画动画化的排斥远超想象——细节失真或角色 OOC 是对产品的反噬。"** —— AI 功能不一定讨好用户
>
> 10. **"看到某个东西觉得能力不错，就可以考虑引用到自己的业务中。"** —— 产品经理需要大量输入

## 十五、学完之后想一想

1. **你的业务中，哪个环节人力成本最高？** 这个环节 AI 能不能帮忙？
2. **你的业务中，哪个流程最慢？** 中间的等待时间能不能用 AI 缩短？
3. **你有没有在用"用户旅程地图"拆解业务？** 试试把你的拆解喂给 AI，让它帮你补充盲点。
4. **你的 AI 产品第一次推给业务部门时，准确率够高吗？** 记住：失去的信任很难挽回。
5. **你每天花多少时间做信息输入？** 关注几个高质量信源，保持对行业趋势的敏感度。
