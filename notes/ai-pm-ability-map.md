# 40k AI 产品经理能力地图

> 基于当前知识库 12 篇笔记提炼，面向年薪 40k 左右（或月薪对应水平）的 AI 产品经理岗位能力要求。

---

## 能力模型总览

40k 的 AI 产品经理不是单纯的"需求翻译官"，而是能够独立负责一个 AI 产品模块或子产品，从 0 到 1 推动落地，并能对业务结果负责的人。

核心定位：**懂业务、懂技术、能落地、会算账**。

---

## 一、基础产品能力（占比 30%）

### 1.1 需求分析与挖掘

| 能力点 | 40k 要求 | 对应笔记 |
|---|---|---|
| 用户旅程地图 | 能独立绘制完整用户旅程，识别 AI 可介入的关键触点 | AI 产品需求挖掘与实战案例 |
| 需求优先级判断 | 用 RICE/ICE 等方法排序，能区分"必须做"和"锦上添花" | AI 项目推动与商业思维 |
| 竞品分析 | 能分析 3-5 个同类 AI 产品，提炼差异化机会 | AI 原型设计与工具实战 |
| 需求文档 | 输出结构清晰、可评审的 PRD | 全部 |

### 1.2 产品设计与文档能力

- PRD：包含背景、目标用户、使用场景、功能描述、交互流程、数据指标、风险点
- 原型设计：能使用 Figma / 即时设计 / Lovable / V0 输出中高保真原型
- 流程图 / 状态图：能清晰表达 AI 产品的决策路径

### 1.3 项目管理与推动

- 能拆解里程碑，制定 2-4 周的迭代计划
- 能组织技术评审、设计评审、用例评审
- 能处理跨团队冲突，推动项目按期上线
- 熟悉 TAPD / Jira / 飞书项目等工具

## 二、AI 专业能力（占比 40%）

### 2.1 AI 技术理解

| 能力点 | 40k 要求 | 对应笔记 |
|---|---|---|
| 模型基础 | 理解 LLM、RAG、Agent、多模态的基本原理和适用场景 | AI Agent 完整学习笔记 |
| 模型选型 | 能根据业务需求在自研 / 开源 / API 之间做选择，并算清成本 | AI 模型选型与评估实战 |
| 提示工程 | 能写出结构化、可复用的 Prompt，知道 few-shot、CoT 等方法 | AI Agent 完整学习笔记 |
| 评测方法 | 能设计评测集、制定评估指标、组织人工/自动评测 | AI 模型选型与评估实战 |

### 2.2 AI 产品设计

| 能力点 | 40k 要求 | 对应笔记 |
|---|---|---|
| 人机协作设计 | 知道何时让人工介入、何时让 AI 自动执行 | AI 产品经理思维升级 |
| 容错与兜底 | 设计幻觉检测、人工审核、异常降级机制 | AI 产品经理思维升级 |
| 上下文管理 | 理解多轮对话、记忆、状态管理的设计要点 | 千问闪购 Agent 意图识别 |
| Agent 设计 | 能设计简单 Agent 工作流（规划 → 执行 → 验证） | AI Agent 完整学习笔记 |

### 2.3 数据能力

| 能力点 | 40k 要求 | 对应笔记 |
|---|---|---|
| 数据驱动 | 能用数据定义问题、验证假设、评估效果 | AI + 数据分析实战 |
| 数据飞轮 | 理解"上线 → 收集数据 → 优化模型 → 更好体验"的闭环 | AI 知识库产品圆桌讨论 |
| 用户标签 | 能设计标签体系，用于个性化或分层运营 | AI + 数据分析实战 |

## 三、业务与商业化能力（占比 20%）

### 3.1 业务理解

- 能快速理解一个业务领域（如销售、客服、电商、教育）的核心流程
- 能找到"AI 能显著提效或增收"的高价值场景
- 能用业务语言与技术团队沟通，而不是只讲功能

### 3.2 商业思维

| 能力点 | 40k 要求 | 对应笔记 |
|---|---|---|
| 成本收益分析 | 能测算 AI 方案的 ROI，包括模型成本、人工成本、收益 | AI 项目推动与商业思维 |
| 商业画布 | 能用商业画布梳理产品模式 | AI 项目推动与商业思维 |
| 定价策略 | 了解按量付费、订阅制、效果付费等 AI 产品常见定价模式 | AIGC 产品机会判断 |

### 3.3 机会判断

- 能判断一个 AI 产品机会是否值得做
- 能识别 PMF 信号
- 能区分"伪需求"和"真需求"

对应笔记：AIGC 产品机会判断

## 四、高阶软能力（占比 10%）

### 4.1 跨团队沟通

- 与算法工程师：能讲清楚业务目标，理解技术约束
- 与设计师：能一起打磨 AI 交互体验
- 与运营/销售：能获取一线反馈，推动产品迭代

### 4.2 学习与迭代

- 能快速学习新技术、新工具
- 能从失败案例中总结方法论
- 能持续跟踪 AI 领域最新进展

### 4.3  Owner 意识

- 对产品的业务结果负责
- 能主动发现问题、推动解决
- 能在资源有限时找到最优解

## 五、40k 能力自检清单

用以下清单给自己打分（1-5 分）：

### 基础能力

- [ ] 我能独立输出一份完整 PRD
- [ ] 我能绘制用户旅程地图并找到 AI 切入点
- [ ] 我能用数据说明一个功能是否值得做
- [ ] 我能推动一个项目从立项到上线

### AI 专业能力

- [ ] 我能向非技术人员解释清楚 RAG 和 Agent 的区别
- [ ] 我能为一个 AI 功能选择合适的模型并算清成本
- [ ] 我能设计 Prompt 并知道如何评测效果
- [ ] 我能设计 AI 产品的兜底和人工介入机制

### 业务与商业化能力

- [ ] 我能快速理解一个新业务领域的核心流程
- [ ] 我能测算一个 AI 功能的 ROI
- [ ] 我能判断一个 AI 产品机会是否值得投入

### 高阶软能力

- [ ] 我能与技术团队有效沟通需求和约束
- [ ] 我能在项目遇到阻塞时主动找到解决方案
- [ ] 我能从失败中提炼可复用的方法论

**评分标准**：
- 4.5-5.0 分：已经具备 40k 水平
- 3.5-4.4 分：接近，需要针对性补强
- 2.5-3.4 分：还在初级水平，需要系统学习
- 低于 2.5 分：需要大量基础训练

## 六、从能力到产出的转化路径

```
学习原理（笔记）
    ↓
使用模板（PRD/画布/决策表）
    ↓
填入真实业务场景
    ↓
输出可评审的项目文档
    ↓
上线并收集数据
    ↓
迭代优化
```

## 七、推荐学习顺序

如果你刚入门，建议按这个顺序学习当前知识库：

1. **AI 产品经理思维升级**——建立基础认知
2. **AI 产品需求挖掘与实战案例**——学会找需求
3. **AI 模型选型与评估实战**——学会技术决策
4. **AI 项目推动与商业思维**——学会推动落地
5. **AI Agent 完整学习笔记**——理解 Agent 产品
6. **AIGC 产品机会判断**——学会机会判断
7. **AI 原型设计与工具实战**——提升产出效率
8. **AI + 数据分析实战**——强化数据能力
9. **AI 知识库产品圆桌讨论**——理解知识库产品
10. **Table as Search / 千问 Agent**——进阶技术理解
11. **Codelive Skills**——工具化思维

## 八、40k 水平的关键分水岭

| 初级（20-30k） | 40k |
|---|---|
| 接需求、写 PRD | 主动发现需求、定义问题 |
| 功能设计 | 系统设计 + 体验设计 |
| 不懂模型 | 能选型、能评测、能算账 |
| 只关注功能上线 | 关注业务结果和数据闭环 |
| 被动执行 | 主动推动、解决阻塞 |
