## 一、核心主题一句话

> **模型能力已经够了，缺的是 PM 把模型能力和真实用户需求连接起来。未来 6-9 个月会有一批真正新颖的 AIGC 应用出现。**

---

## 二、市场现状：悲观 vs 乐观

### 上半年的悲观情绪

| 悲观理由 | 主讲人回应 |
|---------|-----------|
| GPT-5 迟迟不发，模型能力到顶了？ | 去年 12 月的模型能力已经超过大部分市场需求 |
| 除了 ChatGPT，没有第二个日活千万、营收过亿美元的 AI 产品 | 渗透率还太低，不能仅凭 5% 用户的需求判断未来 |
| 一级市场投资遇冷 | 给开发者时间，6 个月后会有新产品爆发 |

### 主讲人的乐观依据

```
1. 模型能力已经远超当前大部分应用场景的需求
2. 真正投入学习 AI 的从业者比例还很小
3. 越来越多连续创业者正在进入，产品会在下半年密集发布
4. 全球 AI 产品用户渗透率不到 5%，还有 95% 的市场空间
```

> 💡 **关键判断**：不是模型不行了，是我们还没把模型用到对的地方。

## 三、为什么应用还没爆发？

### 核心原因

> **模型能力过剩，但应用没跟上。**

```
技术边界        市场需求
   │              │
   ▼              ▼
  已经够远了     大部分人还没理解能做什么
  │              │
  └────── 鸿沟 ──┘
         ↑
    这就是 PM 的机会
```

### 自媒体制造的焦虑

- 公众号经常制造泡沫和焦虑
- 今天说某个东西特别厉害，明天又说没用
- 最好的应对方法：**真正投入工作、学习、研究和使用产品**

## 四、硅谷 vs 中国：机会差异

| 地区 | 主流创业方向 | 原因 |
|------|-------------|------|
| **硅谷** | SaaS（企业服务） | 人力成本高，SaaS 节省成本明确 |
| **中国** | 有 C 端机会 | 用户基数大、场景多元、社交/内容需求强 |

> 💡 **启示**：不要照搬硅谷模式。在中国，C 端和情感/内容方向可能更有机会。

## 五、值得做的方向

### 方向 1：情感中介（Emotion Agent）

> 人用一生都在寻找反馈和连接，AI 可以持续生成内容来建立情感联系。

| 案例 | 说明 |
|------|------|
| **AI 朋友圈** | 分析你最近 10 张照片，让 AI 角色来点赞/评论/吹捧/吐槽 |
| **孙子收音机** | 用儿孙的声音给老人读评书、播新闻，跨代情感连接 |
| **已故亲人的照片动起来** | 让老照片里的人和现在的人互动、拥抱 |
| **Character AI / 星野 / 筑梦岛** | 情感陪伴类产品，日活和用户粘性都很高 |

> 💡 **核心洞察**：人类的情感并不理性。即使知道对方是机器人，人还是会被影响。

### 方向 2：内容供给的暴力破解

> 在需求无限旺盛但供给不足的地方，用 AIGC 大规模生产内容。

**案例：同人图**

```
传统方式：
  一个画手一个月画 1-2 张图
  需求无限，供给严重不足

AIGC 方式：
  100 种穿衣风格 × 1000 种场景 = 100 万种组合
  一次性生成，供用户反复消费
```

**案例：短视频营销素材**

```
传统方式：
  拍一条音画同步的营销视频：200-300 元/条

AIGC 方式：
  上传商品图片 + 手机拍摄视频
  AI 提取内容 → GPT 写 100 种脚本 → 生成视频
  边际成本：0.5-0.6 美元/条，售价 2 美元
```

> 💡 **核心逻辑**：不是推荐内容给用户，而是先把所有可能性生成出来，让用户自己发现喜欢的。

## 六、暂时不建议做的方向

### 1. 为 AI 做新硬件

| 案例 | 问题 |
|------|------|
| **Rabbit R1** | 一个 APP 就能解决的事，非要塞到硬件里 |
| **AI 眼镜** | 如果没有新的使用场景，不如用 AirPods 或手机 |

> 💡 **原则**：不要为了硬件而硬件。除非新硬件能创造新的使用场景。

### 2. Trip Planner（AI 旅行规划）

**为什么不看好？**

```
问题 1：供给决定一切
├─ 酒店满了，再完美的行程也没用
├─ 博物馆要提前两个月预约
└─ AI 解决不了真实世界的供给约束

问题 2：旅游决策很浅
├─ 大部分旅游都是同质化的（去重庆就是那几个景点）
├─ 用户更关心价格，而不是 AI 规划的行程
└─ 提供的价值增量太小
```

### 3. 电商/外卖/生活消费的 AI 助手

- 供给端决定了绝大部分决策成本
- AI 的价值增量可能只有一点点提升
- 有时候不如搜索的过滤/排序功能高效

> 💡 **判断标准**：如果一个场景的价值增量很小，或者供给是决定性因素，暂时不要做。

## 七、AI 产品的三种价值逻辑

### 1. AI = 人类：扩大规模，而不是替代 10 个人

```
❌ 错误思路：
  AI 替代 10 个员工 → 公司产能不变，只是省了 10 个人的工资
  但系统实施和沟通成本可能高于省下来的人力

✅ 正确思路：
  以前因为管理/招聘限制，团队只能招 10 个人
  AI 让产能可以扩展到 100 人、1000 人的规模
```

**案例**：小红书账号自动运营
- 以前：代运营无法做到 7×24 小时、多账号互动
- 现在：AI 自动生成内容、评论、私信回复

### 2. AI > 人类：把智能部分的价值包装出来

> 大模型在很多任务上已经超过 99% 的普通人。

**案例**：阿里官网新口号
- AI 写口号的能力超过阿里 90% 的人
- 重点不是它消耗了多少 token，而是产出的价值

**案例**：AI 营销视频
- 音画同步的短视频，配乐和语音对转化率影响巨大
- AI 能把成本从 200 元/条降到 2 美元/条

> 💡 **关键**：付费点要和客户业务结果结合，而不是按 token 计费。

### 3. AI 扩展人类边界：让不会的人也能做

| 过去不会做的事 | 现在 AI 让普通人能做 |
|--------------|-------------------|
| 写代码 | 设计师 + GPT4 做出 iOS App |
| 做 PPT | 外卖员给儿子做孔子主题 PPT |
| 3D 建模 | 不用打开 Sketch/3D Max，直接生成 3D 模型 |
| 音视频流处理 | 非专业开发者也能做实时音视频应用 |

> 💡 **核心洞察**：不要只盯着专业用户。很多朴素的使用场景因为工具太难学而从未被满足。

## 八、生成的本质：新的创作形式

### 生成不只是"输出一张图"

> 通过 ComfyUI 等低代码工作流，你可以参与整个生成 pipeline，而不仅仅是看最终结果。

```
传统使用方式：
  输入 prompt → 得到图片
  （你只控制输入和输出）

ComfyUI 方式：
  拖拽节点 → 搭建完整的生成 pipeline
  你可以控制采样器、LoRA、ControlNet、后期处理等每个环节
  （你参与创作过程本身）
```

### 为什么这很重要？

- 如果只使用 ChatGPT，不看底层 workflow，会错过模型的核心能力
- 妙鸭相机的成功就是基于 Stable Diffusion 生态的快速创新
- 理解生成过程，才能设计出更有创造力的产品

## 九、零提示与上下文触发

### 两个关键设计原则

```
Zero Prompt（零提示）
├─ 用户不需要输入任何信息
├─ 直接享受 AIGC 内容
└─ 例：打开 App 就自动生成内容

Low Prompt（低提示）
├─ 用户只需要输入很少信息
├─ 系统帮用户扩展 prompt
└─ 例：上传 PDF，系统自动用"读论文"或"读财报"的 prompt 处理
```

### Prompt 暗增强

> 用户输入一个简单的指令，系统在背后扩展成高质量 prompt。

**案例：Kimi 读财报**

| 普通产品 | Kimi |
|---------|------|
| 用户："帮我读一下这份财报" | 用户："帮我读一下这份财报" |
| 直接扔给模型 | 系统暗增强：调用"读财报"专用 prompt |
| 输出质量一般 | 输出摘要、关键指标、风险点 |

> 💡 **原则**：不要让用户自己写好 prompt。产品要帮用户写好。

### Context Trigger（上下文触发）

> 不要总是等用户主动提问。利用手机提供的上下文信息主动触发 AI。

```
可用上下文：
├─ 地理位置
├─ 时间
├─ 日程安排
├─ 网络状态
├─ 最近使用记录
└─ 用户当前正在做的事

案例：
  你设定 AI 角色是"偶像练习生"
  他每天 9-11 点练舞
  你 9:30 发消息，他不会回复
  11:05 他主动回："宝贝，刚练完舞，你找我什么事？"
```

> 💡 **关键问题**：AIGC 的价值来自"G"（Generation），如果总是等用户刺激，那和搜索有什么区别？

## 十、内容型公司的未来

### 可能出现的新形态公司

```
传统公司：
  有 App、有网站、有广告、有小程序

未来内容型公司：
  只有 20-30 个人
  没有自己的平台
  产品 = 高质量内容
  通过 AI 在全渠道生产、分发内容
  用内容能力吸引用户、影响用户
```

### 内容消费 vs 内容生成

| 误区 | 正确理解 |
|------|---------|
| 让用户自己生成内容 | 用户来消费优质内容，不在乎是不是自己生成的 |
| 创作者和观众比例固定 | AIGC 可能把创作者比例从 5% 提升到 20% |
| 生成只是玩玩 | 预生产大量内容供反复消费，才是价值 |

> 💡 **核心判断**：消费者要的是好内容，不是生成这个动作。

## 十一、给产品经理的启发

1. **不要被自媒体情绪带跑**——真正下场去用产品、读论文、做 demo
2. **模型能力已经够了**——差距在于 PM 的理解和连接能力
3. **情感和内容供给是巨大的机会**——尤其是被忽视的朴素需求
4. **不要碰供给约束型场景**——旅行、电商助手暂时价值增量小
5. **不要为硬件而硬件**——除非新硬件创造新场景
6. **帮用户写好 prompt**——零提示/低提示是产品成功关键
7. **让 AI 主动触发**——利用上下文创造新体验
8. **关注内容消费端**——不只是让 20% 的人创作，要让 80% 的人有东西看

## 十二、关键术语表

| 术语 | 含义 |
|------|------|
| **PMF** | Product-Market Fit，产品市场匹配 |
| **RAG** | Retrieval-Augmented Generation，检索增强生成 |
| **Embedding** | 将文本/图片等转成向量，用于语义检索 |
| **Token 计费** | 按模型处理的 token 数量收费 |
| **ComfyUI** | Stable Diffusion 的低代码工作流界面 |
| **LoRA** | 轻量级模型微调技术 |
| **ControlNet** | 控制图像生成结构和姿态的技术 |
| **暗增强** | 产品在后台自动扩展用户输入的 prompt |
| **Context Trigger** | 利用上下文信息主动触发 AI 行为 |
| **Zero Prompt** | 用户无需输入，直接消费 AI 生成内容 |
| **Low Prompt** | 用户少量输入，系统补全高质量 prompt |
| **AIPPT** | AI 自动生成 PPT 的工具 |
